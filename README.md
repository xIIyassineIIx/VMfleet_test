# Simple Calculator

A tiny, dependency-free calculator that runs in the browser.

## Features

- Add, subtract, multiply, and divide
- Chained operations (e.g. `2 + 3 × 4` evaluates left to right as a basic calculator)
- Decimal input, sign toggle, backspace, and clear
- Full keyboard support
- Responsive layout with focus states for accessibility

## Run it

Open `index.html` in any modern browser. No install or build step required.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter a digit |
| `.` or `,` | Decimal point |
| `+` `-` `*` `/` | Operator |
| `Enter` or `=` | Equals |
| `Backspace` | Delete last digit |
| `Esc` or `C` | Clear all |

## Files

- `index.html` — markup and keypad
- `styles.css` — dark theme and layout
- `script.js` — calculator logic
